# 🎮 Rock-Paper-Scissors Game

A command-line Rock-Paper-Scissors game built using Python. The player competes against the computer, with the computer making a random choice for each round.

## 🚀 Features

- Rock, Paper, and Scissors choices
- Random computer selection
- Win, lose, and tie detection
- Score tracking
- Multiple rounds
- Input validation
- User-friendly command-line interface

## 🎯 Game Rules

- Rock beats Scissors
- Scissors beats Paper
- Paper beats Rock
- Same choices result in a tie
